# Ramesh Kandli — Premium Website

## Files
- `index.html` — page structure and content
- `css/style.css` — original visual design plus premium responsive/effect layer
- `js/main.js` — navigation, filters, gallery viewer, theme, search, scroll effects and contact email draft

## Run locally
Open `index.html` in a modern browser. For best results, upload the entire folder to your web host while keeping the `css` and `js` folders beside `index.html`.

## Notes
- Existing profile text, social destinations, and original embedded visual assets have been retained.
- Gallery cards currently remain stylized placeholder memories; replace them with real photos when ready.
- The contact form opens the visitor's email app with a prefilled message. It does not silently send email; a hosted form endpoint is needed for direct submission.
- Google Fonts need an internet connection; system fallback fonts are included.
